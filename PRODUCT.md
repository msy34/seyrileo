# Seyrileo — product contract

Working brand: **Seyrileo** (provisional; no trademark, domain or App Store name check has
been done). Promise: *Your streams. Your space.* — TR: *Kendi yayınların. Kendi düzenin.*

The display name is a build setting (`APP_DISPLAY_NAME`). Persisted keys (Keychain service
`provider-credentials.v1`, `Application Support/Sources/sources.json`) are brand-neutral, so
a rename does not orphan user data.

## What it is

A native SwiftUI media player for iPhone and iPad that plays **Xtream-compatible sources the
user is authorized to access**. Provider login is the provider's account, not a Seyrileo
account.

## Boundaries (non-negotiable)

- We do not sell, recommend or bundle IPTV content, playlists or subscriptions.
- No stream proxying, DRM bypass, credential discovery or panel admin APIs.
- No copyrighted channel logos/posters in demo assets. All demo media is generated by
  `scripts/generate-fixture-media.sh` from ffmpeg test-pattern generators.
- v1 has no own auth server, AI/RAG, ads SDK, VPN, downloads/recording or third-party
  metadata service.
- The app never claims a capability the source or engine does not provide (no fake
  catch-up, no quality selection on single-quality streams, no "plays every format").

## v1 feature contract

The authoritative list is the 12-point contract from the planning document; per-item status
is tracked in [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md). In short: Xtream setup with
secure credentials; live TV with categories, search, now/next EPG, favorites, recents and
collections; movies; series; EPG guide; multiple isolated sources; personal organization
(aliases, hide, reorder); parental PIN/biometrics enforced on every route; audio/subtitle
selection, PiP and AirPlay where verified; diagnostics, bounded retries, redacted support
export, data deletion, accessibility, TR/EN; local program reminders; StoreKit 2
non-consumable Pro.

**Free:** one source, core playback, basic EPG/favorites, one custom collection, all error
handling, accessibility and supported PiP/AirPlay. **Pro:** multiple sources, unlimited
collections, advanced organization, reminders. No ads. Price only from StoreKit.

## Deferred

tvOS UI, M3U import (beyond Xtream EPG), iCloud sync, profiles, Chromecast, Trakt, TMDb,
external subtitles, VPN, recording, downloads, multi-screen, AI. Catch-up only after a
capability-gated provider adapter is verified.

## Information architecture

Tabs: **Your Space · Live · Library · Search · Settings** (iPad: sidebar via
`.sidebarAdaptable`). Library = Movies + Series. Diagnostics live in a secondary sheet.
Visual direction: midnight blue (`#101622`) canvas, teal accent (`#48D5C1` dark /
`#007A6E` light for contrast), system fonts, restrained motion, Dynamic Type, VoiceOver,
Reduce Motion.

## Release posture

Nothing is "App Store ready" until owner-supplied items exist: bundle ID, team, product IDs,
privacy/support URLs, rights documentation, a live authorized review account, trademark
checks. See [docs/RISKS.md](docs/RISKS.md).
